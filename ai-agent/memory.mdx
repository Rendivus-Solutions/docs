---
title: "What the agent remembers"
description: "The notes Raddivus keeps about you and your brands, and how to read, change, or delete them."
---

The agent keeps notes on what it learns as you talk to it, and carries those notes into every later conversation. Tell it once that you run an agency with eight client accounts, or that you want short replies with no preamble, and you will not have to say it again in the next chat.

**Where:** Settings → **Memory**. **Cost:** 0 credits. **Plans:** Professional and VIP for the agent to keep writing notes. Existing notes stay readable, editable and deletable on every plan.

## The two sets of notes

There are exactly two, and this is the whole model.

- **About you.** Follows you across every brand. Things that are true of you, not of one client.
- **About {your brand}.** One set per brand, and it stays with that brand. What the agent learns while you work on one brand never shows up while you work on another.

Conversation transcripts are a separate thing and they do not carry over. Opening a new chat does not give the agent the text of an older chat. Only the notes carry, and you can read every word of them.

## What you can do

Open Settings → **Memory**. Both sets are shown as plain text.

| Action               | What it does                                                       |
| -------------------- | ------------------------------------------------------------------ |
| **Edit**             | Change the text directly. It is a text box, not a locked list      |
| **See what changed** | Shows what the agent changed and when, with the previous version   |
| **Restore**          | Puts an earlier version back, in one click                         |
| **Clear**            | Empties one set of notes                                           |
| **Delete all**       | Removes every note and the change history. This cannot be undone   |
| **Turn off**         | Three switches: everything, "About you", or one brand at a time    |

## Turning it off does not delete anything

Your notes stay where they are and stay readable. The agent stops adding to them and stops using them. Turn it back on and it picks up where it left off.

Deleting is a separate, deliberate action.

## If it gets something wrong, or drops something

If a note is wrong, edit it or clear that set.

If a note you wanted is gone, every rewrite is saved in full, so open **See what changed** and restore the earlier version. We keep the last 20 versions of each set of notes and 90 days of history.

## How the notes get written

After the agent finishes replying, a small fast model looks at that exchange and decides whether anything in it is worth keeping. Most messages produce nothing.

Each set of notes stays short on purpose, around a paragraph or two. When it fills up, the agent tightens the wording rather than asking you to prune it. That is also why the change history matters: if a rewrite drops a detail, you can put it back.

## Cost and plans

Writing, reading, editing, restoring and deleting are all **0 credits**.

Memory is part of the AI Agent, so the **Professional** or **VIP** plan is needed for the agent to keep writing new notes. If you move down to Starter, your existing notes stay readable and you can still edit, restore and delete them. Deleting what a product wrote about you should never depend on your plan.

## Privacy

Notes are tied to your account. Team members never see each other's notes, and nothing learned about one user is used for another.

Deleting a chat does not delete the notes, and deleting the notes does not delete the chats. To remove both, do both.

<Note>
  Memory has its own switches in Settings → Memory. They are separate from the
  five toggles in the [AI Permissions panel](/ai-agent/permissions), which
  control what the agent can do with your ad account.
</Note>
