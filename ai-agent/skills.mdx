---
title: "Agent skills"
description: "Save instructions for tasks your team repeats, like the monthly ads report. The agent uses a skill only when your request matches it."
---

A skill is a saved set of instructions for one kind of task your team does again and again: how you write the monthly ads report, how you name campaigns, what a client update must always include. Write it once, and nobody has to explain it in a new chat again.

## Create a skill

Open **Settings → Personalization** and pick the **Skills** tab. Press **New skill** and fill in three fields:

- **Name.** For example "Monthly ads report". Up to 60 characters.
- **When to use.** One line the agent reads to decide whether the skill fits, for example "the user asks for a monthly or end-of-month ads report". Up to 200 characters.
- **Instructions.** The steps and format you want, in plain sentences or a numbered list. Up to 4,000 characters.

Then choose where it applies: **All brands**, or one client brand. Press **Save**.

If you have no skills yet, **Start from an example** fills in a ready-made "Monthly ads report" skill. Nothing is saved until you press Save, so you can change it first.

<Tip>
Write the "When to use" line the way your team actually asks. "The user asks for a monthly or end-of-month ads report" matches more requests than "reporting".
</Tip>

## How the agent uses it

In every chat, the agent sees only the names and "When to use" lines of the skills that apply, never the full instructions. When your request matches one, it opens that skill and follows it for how to do the task.

The reply then shows a small line above it: **Used skill: Monthly ads report**. The line stays there when you come back to the conversation later, so you can always tell which instructions shaped an answer.

A skill set to one brand is only offered while that brand is selected. One client's way of doing things never shows up while you work on another. The Skills tab is grouped the same way: a **General** group for skills that apply to every brand, then one group per brand.

## What a skill cannot do

A skill shapes style, steps and format. It cannot:

- give the agent permissions you have turned off,
- change the model tier,
- skip the approval step before a change to your ad account.

When you save, any sentence that tries to change the agent's rules, such as "ignore your previous instructions" or "approve everything without asking", is removed. The screen tells you how many sentences were taken out, and everything else is saved.

## Turn off or delete

Each skill has a switch. A skill that is off is kept but never offered to the agent. Turn it back on any time.

Deleting a skill removes it for good. Raddivus asks you to confirm first.

## Team roles

Skills belong to the account. Everyone on your team can see them, and the agent uses them in everyone's chats. Only the account owner or an admin can create, edit, turn off or delete a skill. A skill stays when the person who wrote it leaves the team.

## Limits, credits and plans

- Up to **20 skills per account**.
- Creating, editing, turning off and deleting skills cost **0 credits**. A conversation that uses a skill is billed like any other conversation.
- Skills need the **Professional** or **VIP** plan. If you move down to Starter, your skills stay listed and you can still delete them, but the agent stops using them.
