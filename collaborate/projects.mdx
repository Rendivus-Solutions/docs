A project is one piece of work for a brand: a launch, a seasonal campaign, a website refresh. It holds the tasks for that work, the people doing it, optional phases, the documents that go with it, and short progress updates you can send to your client. Ads you generate for it are kept inside it too, following its own instructions.

**Where:** sidebar → **Tasks** → the **Projects** switch at the top. Also the **Project** chip in the [Ad Generator](/create-ads/ad-generator) and the **Project** field in the [Ad Copier](/create-ads/ad-copier). **Cost:** free; only an AI-drafted update costs credits (see [Updates](#updates)). **Plans:** all.

## Create a project

<Steps>
  <Step title="Open Tasks and switch to Projects">
    The **Tasks / Projects** switch sits at the top of the Tasks page.
  </Step>
  <Step title="Press New project">
    Give it a name (up to 80 characters, unique within the brand). Optionally
    add a start and end date and custom instructions for the AI (see below).
  </Step>
  <Step title="Pick its people">
    You are on it from the start. Add the teammates who work on it. On a team
    account, the window says who will be able to see the project.
  </Step>
</Steps>

You can also make a project from the **Project** menu in the Ad Generator or the Ad Copier (**New project…**), or from an existing task: see [Turn a task into a project](#turn-a-task-into-a-project).

## The Projects list

The list shows open projects first, then Done ones, with Archived projects folded away. Each row shows the project's state, its people and its progress:

- **8/14 done**: tasks finished out of all its tasks.
- **Days left** until the end date, and how many tasks are **overdue**.
- **At risk**, when an Active project with an end date has an overdue task, has passed its end date with work left, or is past half its time while the finished work trails far behind.

Click a row to open the project's page.

## States

A project is **Planned**, **Active**, **Done** or **Archived**. A new project starts Active. Only Planned and Active projects are offered when you start new work (a new task, a new ad run). Change the state from the **State** menu on the project page; reopening a Done project is the same menu.

## The project page

- **Brief:** what the project is about.
- **Tasks:** every task in the project, grouped by phase once the project has phases ("No phase" comes last). Sub-tasks sit under their parent. **Add task** opens the New task window with the project already picked. **Open in Tasks** shows the same tasks in the full task list, filtered to this project.
- **Phases** (optional): a name and an optional date each, with their own progress. Press a phase's name to rename it or change its date.
- **Documents:** link a [Knowledge Base](/brands/knowledge-base) document, or **Add a file**, which uploads it to the brand's Knowledge Base and links it here. Unlinking a document never deletes it.
- **Updates:** see below.
- The details column on the right shows the state, the dates, the progress and the people, and on team accounts who can see the project.

## Tasks in a project

A [task](/collaborate/tasks) belongs to one project or to none. Pick the project in the New task window or on the task itself; a sub-task always follows its parent. Every task in a project carries the project's name in the task list and on the board, and the **Project** filter narrows the list to one project (you can keep it in a saved view).

Assigning a project task to a teammate who is not on the project puts them on it, and a message tells you so.

### Turn a task into a project

When a task has grown into a whole piece of work, open its **…** menu and choose **Turn into project** (offered on a task with sub-tasks). Its sub-tasks become the project's tasks, the task itself stays in the project, and the project's page opens.

## Updates

Keep your client posted without writing from scratch.

- **Write update** opens an editor for a note in your own words.
- **Draft weekly update** asks for a period (the last 7, 14 or 30 days). The AI writes three short sections, **Done**, **Next** and **Blocked**, only from what really happened to the project's tasks in that period: what was finished, what is due in the next 7 days, what is blocked and why, and what is late. The draft opens in the same editor for you to change before you press **Save update**.

Saved updates are listed newest first, each with a **Copy** button so you can paste it into an email or a message. Raddivus never sends an update to anyone. The person who wrote an update, the account owner and admins can edit or delete it.

<Note>
Writing an update yourself is free. Each AI draft costs the same as one Raddivus Lite message in the [AI Agent](/ai-agent/overview) and needs the AI Agent on your plan. If nothing happened in the period you picked, no draft is written and nothing is charged.
</Note>

## Close a project

Choosing **Done** in the State menu opens **Close this project**:

- **Draft a recap:** the AI writes "What was done" and "What was learned" from the whole project. Edit it, then press **Save recap and close**. The recap shows first in the project's Updates.
- **Close without a recap.**

A recap costs the same as a weekly update draft.

## Ads in a project

Pick a project in the Ad Generator or the Ad Copier and the run is saved inside it. Every visit starts on **No project**, and we never pick the last project you used for you, so a run never ends up in a project by accident.

**Custom instructions** (optional, up to 2,000 characters) are what the AI should always do for ads in this project: the offer, the audience, the angle, things to avoid. They are added to every run inside the project, together with your brand profile and anything you type for that one run.

Your history shows which project each run belongs to. Once at least one run on screen belongs to a project, a filter appears above the history so you can show **All projects**, **No project** or a single project. When you edit an image, the new version stays in the same project as the original.

## Mention a project in the AI Agent

In the [AI Agent](/ai-agent/overview), type `@` and pick a project from the **Projects** section. The agent reads the project's state, dates, brief, phases, tasks, documents and latest updates, so you can ask "what's late on @Spring Campaign?" or "write three headlines for @Q4 Launch".

## Who sees a project

A project has its own people. On a team account, only the people on a project, the account owner and admins can see it, its tasks and the ad runs made inside it. For everyone else it does not appear anywhere: not in pickers, history, the task list or the AI Agent.

- Anyone on a project can add or remove people.
- Someone taken off a project comes off its tasks.
- Someone who leaves the team comes off every project. The project stays with the brand.

Slack answers about tasks leave out tasks that belong to a project, because Slack cannot tell who is asking.

## Deleting a project

<Warning>
Deleting a project also deletes its tasks and every ad run generated inside it. The confirmation tells you how many tasks and runs will be removed before you confirm. Ads you already saved to a folder are kept, because a saved ad is its own copy.
</Warning>

Only the person who made the project, the account owner or an admin can delete it. For anyone else, **Delete** is not offered.
