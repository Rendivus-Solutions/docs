---
title: "Projects"
description: "Group your ad runs into projects with their own instructions, inside the Ad Generator and the Ad Copier."
---

A project is a folder inside a brand for one thread of work: a launch, a seasonal offer, one audience. Give it a name and, if you like, custom instructions. Every ad you generate inside the project follows those instructions, on top of your brand's own voice.

**Where:** the **Project** chip in the [Ad Generator](/create-ads/ad-generator) and the **Project** field in the [Ad Copier](/create-ads/ad-copier). **Cost:** free. **Plans:** all.

## Create a project

<Steps>
  <Step title="Open the Project menu">
    In the Ad Generator it is the first chip under the prompt box (in the
    Advanced canvas view, the first pill on the options strip). In the Ad
    Copier it is the **Project** field in the form.
  </Step>
  <Step title="Choose New project">
    Give it a name (up to 80 characters, unique within the brand).
  </Step>
  <Step title="Add custom instructions (optional)">
    Write what the AI should always do for ads in this project: the offer, the
    audience, the angle, things to avoid. Up to 2,000 characters.
  </Step>
  <Step title="Generate">
    The new project is picked for you. Generate as usual; the run is saved
    inside the project.
  </Step>
</Steps>

With a project picked, the same menu also lets you **Edit** or **Delete** it.

## No project is fine

Projects are optional. Every visit starts on **No project**, and we never pick the last project you used for you, so a run never ends up in a project by accident.

## Custom instructions

Instructions are added to every run inside the project, together with your brand profile and anything you type for that one run. Use them for the things you would otherwise repeat each time, like "Always mention free shipping" or "Speak to first-time homeowners".

## Find runs by project

Your history shows which project each run belongs to. Once at least one run on screen belongs to a project, a filter appears above the history so you can show **All projects**, **No project**, or a single project. When you edit an image, the new version stays in the same project as the original.

## Mention a project in the AI Agent

In the [AI Agent](/ai-agent/overview), type `@` and pick a project from the **Projects** section. The agent gets the project's name and custom instructions, so "write three headlines for @Q4 Launch" follows that project's brief. It does not read the ads generated inside the project yet.

## Teams

Projects belong to the brand, not to the person who created them. Everyone on your team who works on that brand sees the same projects and can use, edit, and delete them. If the person who created a project leaves the team, the project stays with the brand.

## Deleting a project

<Warning>
Deleting a project also deletes every ad run generated inside it. The confirmation tells you how many runs will be removed before you confirm. Ads you already saved to a folder are kept, because a saved ad is its own copy.
</Warning>
