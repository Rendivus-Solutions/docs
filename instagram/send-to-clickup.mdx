---

Once a post is finished (text and visual done), you can push it to ClickUp as a task.

**Where:** sidebar → **IG Content**. **Cost:** free. **Plans:** Growth and VIP (requires a [ClickUp connection](/connections/connect-clickup)).

## Send a post

<Steps>
  <Step title="Open the post">
    Open the post's edit modal and click **Send to ClickUp**.
  </Step>
  <Step title="Map fields (first time only)">
    The first time you push a post into a given list, a one-time field mapper
    appears. Choose which generated field (title, caption, hashtags, scheduled
    date and time, visual brief, composed image, or published link) lands in
    which ClickUp slot (task name, description, tags, due date, attachment, or
    any custom field). Save the mapping.
  </Step>
  <Step title="Done">
    The post is pushed as a ClickUp task with a "View in ClickUp" link.
  </Step>
</Steps>

## How the mapping is remembered

The mapping is saved **per brand and list**, so every later post from the same brand sends to that list in one click.

- Sending the same post again to the **same list** updates the existing task instead of creating a duplicate. This is a one-way sync.
- Sending to a **different list** creates a new task, which is useful when you want the same post on multiple boards.

## Troubleshooting

<AccordionGroup>
  <Accordion title="The button is disabled">
    Connect ClickUp under [Settings →
    Connections](/connections/connect-clickup), and make sure the post is
    finished.
  </Accordion>
  <Accordion title="The image didn't attach">
    The task still succeeds. Re-send the post to update the same task, or
    confirm the visual finished composing first.
  </Accordion>
</AccordionGroup>
